## 🔧 三处核心修复（Diff 摘要）

### 1️⃣ `data_bridge.py` — 字段别名补齐

```python
# 修改前
"trend":        ["trend", "trend_dir", "trend_state"],
"location":     ["location", "sr_level", "pivot"],

# ✅ 修改后
"trend":        ["trend_raw", "trend", "trend_dir", "trend_state"],
"location":     ["location_raw", "location", "sr_level", "pivot"],
```

**根因**：`real_data_source.py` 输出 `*_raw`，桥接层不认 → 全部静默丢失

### 2️⃣ `batch_backtest.py` — Degraded 单一源

```python
# 修改前（双重计算 → 不一致）
degraded_count = sum(1 for r in records if r["decision"].degraded)

# ✅ 修改后（全程透传）
degraded_count = sum(1 for r in records if r.get("_degraded", False))
```

**根因**：加载层 vs 汇总层各算各的 → 13 vs 270 完全对不上

### 3️⃣ `batch_backtest.py` — Source 键兼容

```python
# 修改前
source = row.get("source", "unknown")

# ✅ 修改后
source = row.get("_source", row.get("source", "unknown"))
```

**根因**：数据源写 `_source`，读取找 `source` → 全部归为 unknown
