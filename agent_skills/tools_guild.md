# Agent Tools Guide & Operational Rules

This document outlines the tools available for the AI development agent within the project environment.

## Available Tools

### 1. run_python_script
- **Description**: Execute a specified Python script using the local active environment and return its standard output and error streams.
- **Parameters**:
  - `script_path` (string): Relative path to the target Python script (e.g., `tests/test_openai.py`).

### 2. read_skills_guide
- **Description**: Read and load project instructions or workflow guidelines.
